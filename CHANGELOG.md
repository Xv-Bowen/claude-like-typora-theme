# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning for public releases.

## [1.0.0] - 2026-08-12

### Added

- Independently tuned Claude Light and Claude Dark themes.
- Warm neutral surfaces with a shared clay accent system.
- Long-form Chinese and mixed-language typography.
- Complete heading, list, task, table, quote, link, footnote, TOC, and metadata styling.
- Fenced code blocks, language labels, syntax highlighting, and source-view styling.
- GitHub-style alerts, Mermaid diagrams, and mathematical content support.
- File list, file tree, outline, search, tabs, menus, footer, and integrated-window refinements.
- Focus mode, typewriter mode, responsive breakpoints, reduced-motion behavior, and print rules.
- English and Simplified Chinese documentation, customization guide, test document, and high-resolution previews.
